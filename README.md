Sales & Customer Data Analysis (SQL Project)

Mục tiêu dự án
Dự án này thực hiện truy vấn và phân tích dữ liệu bán hàng, đánh giá hành vi khách hàng bằng ngôn ngữ SQL nhằm hỗ trợ ra quyết định kinh doanh.
Kỹ năng & Công cụ sử dụng

SQL Queries: `SELECT`, `JOIN`, `GROUP BY`, `HAVING`, Aggregate Functions (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`).
Phân tích thống kê: Tính toán giá trị trung bình (Mean), giá trị nhỏ/lớn nhất (Min/Max) của doanh thu theo khu vực.

Cấu trúc mã nguồn
`query_analysis.sql`: Chứa các câu lệnh SQL truy vấn tổng quan doanh số và phân tích theo khu vực khách hàng.
